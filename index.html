자주 묻는 질문

어그로 제목이란 무엇인가요?
어그로 제목은 클릭(주목)을 유도하기 위해 국내 온라인 커뮤니티에서 널리 쓰이는 제목 형식을 뜻합니다. 명사를 나열하고 끝에 구두점과 확장자를 붙이거나, 숫자·자음을 활용하는 등 정해진 패턴이 반복적으로 관찰됩니다.
점수는 어떻게 계산되나요?
제목의 품사 구조 가중치와 각 단어의 누적 주목도 가중치를 조합한 값을 0~100점으로 정규화합니다. 확장자·숫자·말줄임표·의문형 같은 요소가 있으면 가산점을, 제목이 지나치게 길면 감점을 적용합니다.
왜 제목 끝에 .jpg를 붙이나요?
제목 끝의 ...jpg, ...gif는 이미지나 짤이 첨부되어 있다는 신호로 받아들여져 클릭 유도 효과가 크다는 점이 실제 커뮤니티 제목 데이터 분석에서 확인되었습니다.
개념글과 일반글 계열의 차이는 무엇인가요?
개념글 계열은 조회수 대비 주목도 총합이 높은 단어(근황, 레전드, 논란 등) 중심이고, 일반글 계열은 상대적 주목도 증가폭이 큰 단어(짤, 인증, 싱글벙글 등) 중심입니다. 혼합을 선택하면 두 계열을 함께 사용합니다.
이 계산기는 서버에 데이터를 전송하나요?
전송하지 않습니다. 모든 계산은 브라우저 안에서만 실행되는 정적 페이지이며, 외부 크롤링이나 API 호출 없이 patterns.json 데이터만 불러와 사용합니다.
